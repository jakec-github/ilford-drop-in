Issue #23 · faked prototype

Shift pattern, Overrides and minting a rota

Everything here is faked and kept in this browser only. The RRULEs are evaluated in the page, the same way the server would: in wall-clock time, and starting at midnight on the “Start from” date. Pressing Define rota turns the preview into the “previous rota”, so you can mint batch after batch and see each one carry on from the last.

Presets:
What this prototype decides that you have not
  • An Override can move a shift's start time, but only within its own date. Moving it to another day is not offered.
  • An Override is one RRULE line, not a set.
  • Overrides match the times the pattern generates, even when an earlier Override has moved the shift. Editing the pattern's time leaves time-specific Overrides matching nothing, and the preview says so (your “quirk”).
  • A shift's length is kept when its start moves, so the end moves with it.
  • A Shape set by an Override replaces the whole Shape, rather than adjusting it.
  • When two Overrides pin one volunteer on the same shift, the later one's Role wins. A custom entry can be pinned more than once.
  • Refused in the pattern: DTSTART (“Start from” supplies it), RDATE (no one-off shifts), EXDATE, and FREQ finer than DAILY. Not understood: BYSETPOS, BYWEEKNO, BYYEARDAY and BYSECOND.
  • The minting search gives up five years past the start date, and says how many shifts it found.
  • A rota only takes shifts the pattern generates after the previous rota's last one, compared by the generated start time, not a moved one. There is no start date: a rota that stopped after a morning shift carries on with that evening's. “Leave a gap…” reveals a “not before” date for a break, and it starts a week later. In the real thing, this means storing where the last rota stopped (the generated start of its last shift), because an Override may have moved that shift's actual start.
  • Every “Start from” date, the pattern's and each Override's, defaults to the day it is created. A preset counts as created today, and so does its pretend previous rota.
